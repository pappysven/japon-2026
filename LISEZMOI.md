# Japon 2026 — mise en ligne depuis l'iPad

Fichiers à déposer à la racine du dépôt GitHub : index.html, data.json, sw.js, manifest.webmanifest, allergie.jpg, icon-192.png, icon-512.png, apple-touch-icon.png.

1. github.com → « + » → New repository → nom `japon-2026`, Public, cocher « Add a README » → Create.
2. Dans le dépôt : Add file → Upload files → choose your files → sélectionner les 8 fichiers (dossier dézippé dans Fichiers) → Commit changes.
3. Settings → Pages → Branch : main, dossier / (root) → Save. Attendre 1 à 2 min.
4. Ouvrir https://<ton-compte>.github.io/japon-2026/ dans Safari → Partager → Sur l'écran d'accueil.
5. Lancer l'app depuis l'icône → Pratique → « Prêt à partir ? » → « Tout préparer pour le hors-ligne » (en wifi).

Mise à jour : remplacer data.json (et/ou index.html, sw.js) par Upload files, puis ouvrir l'app deux fois avec du réseau.
Les numéros de réservation et les QR codes restent sur chaque appareil : ils ne sont jamais publiés.
